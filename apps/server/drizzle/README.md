# Database migrations

Generated by `pnpm db:generate` (drizzle-kit) from `src/db/schema.ts`, applied by
`pnpm db:migrate` (`src/db/migrate.ts`) — at deploy, before the new server starts.

- `0000_baseline` is the schema as it was on `main` before migrations existed.
- `0001_…` brings that up to date; it is idempotent so databases created with
  `db:push` (which have no migration history) can be adopted: the runner marks
  the baseline as applied and runs the rest.
- New schema change: edit `schema.ts`, run `pnpm db:generate --name <what>`,
  review the SQL, commit it. Never `db:push` against production.
